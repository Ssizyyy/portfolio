An open-source Claude Code plugin that runs a frontend design pass in a fixed order, and carries a catalog of 750+ ready-made UI components to choose from before anything is hand-built.

$ claude plugin marketplace add Ssizyyy/claude-plugins
$ claude plugin install design-stack@ssizyyy-plugins
> /design-stack:design-pass the Settings and Orders screens
  1. Layout and statesTaste first, picking from the component catalog.
  2. StressWorst-case data: long names, zero items, non-Latin text.
  3. Polish and auditThen a before and after proof.
