The problem

Stock Nextcloud shows a Gregorian calendar, only partly mirrors for right-to-left, and shows Persian names in Latin script. Takta wanted a Persian-first product that a school or company could run on its own server instead of a foreign cloud.

The product needed a front door: sites that explain it in Persian, in the product's own design language, and an admin side that does not need the command line.

What I built

  • Two static Persian websites in Astro 5. A sales site and a showcase site, both right-to-left, with the font self-hosted. Pages carry the product's own calendar, file list and task-board mock-ups, built in HTML.
  • A shutter page transition. Teal slats close and open between pages. It plays on every load and is skipped under reduced motion.
  • Guard rails in the build. Lint scripts reject physical CSS properties (so RTL cannot break), wrong half-spaces in Persian words and banned copy. The build lists any placeholder text still unfilled.
  • An admin app inside Nextcloud. LDAP-synced user creation, groups, roles and user management in Persian.
  • Deployment and backups. An nginx config and a deploy script for the VPS, and daily backups so each organisation's data stays on its own server.
